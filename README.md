# Quiet Front — playtest builds

Download the latest build: **[Quiet-Front.zip](https://github.com/Westsidemez/quietfront-releases/releases/latest/download/Quiet-Front.zip)**

1. Unzip it and drag **Quiet Front** into Applications.
2. Open it. The first time, macOS says it can't verify the app (it isn't notarized by Apple yet).
   Click **Done**, then open **System Settings → Privacy & Security**, scroll down and click **Open Anyway**.
   You only do this once.
3. Updates arrive by themselves: each time you open the game it checks for a new build,
   or use **Quiet Front → Check for Updates…**.

Needs macOS 14 or later (Apple silicon or Intel).
